Morjani Shop Pro

A complete shopping journey, from browsing to order management.

Open live demo ↗GitHub source code ↗

Project overview

Morjani Shop Pro is a responsive marketplace demo designed to showcase a modern e-commerce experience. Orders and data are simulated locally, with no real payments or server authentication.

Key features

Catalog and product pages

Search, categories, filters, wishlist, multi-image galleries and zoom.

Cart and checkout

Shopping cart, discount codes, delivery options and simulated order confirmation.

Customer area and administration

Demo login, order tracking, products, stock, promotions, analytics and reports.

French, English and Arabic interface with RTL support and light/dark themes.

Demo project: data is stored in the browser (localStorage), with no backend or real payments.
