PORTFOLIO OMAR MORJANI
=====================
Ouvrir index.html dans un navigateur pour visualiser le site.
Pour publier : transférer tous les fichiers et le dossier assets/ dans public_html de votre hébergement.
Aucun backend ni base de données nécessaires.
Le formulaire de contact est remplacé par un lien e-mail et un lien WhatsApp qui fonctionnent sans serveur.
La vidéo de démonstration et le CV sont inclus dans assets/.
La police Google Fonts nécessite une connexion Internet (police de remplacement disponible hors ligne).
Avant publication, valider les références, descriptions, informations de contact et le contenu du CV.
